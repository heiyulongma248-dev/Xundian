寻典 Mac 构建说明

一页指南 · 给愿意帮忙在 Mac 上打包的人

这是什么

你拿到的"寻典 Mac 构建包"是一份源代码 + 自动构建脚本。 你只需要在一台 Mac 上花 2-3 分钟，就能产出一个可发给非技术用户的 寻典.app。

📌 你需要的
· 一台 Mac（macOS 10.13 High Sierra 或更新都行；Apple Silicon / Intel 都行）
· 网络（脚本会通过 pip 下载约 50 MB 依赖，仅首次需要）
· Python 3.10 或更新（如未装，脚本会教你怎么装）

三步搞定

  1. 解压"寻典 Mac 构建包.zip" 到桌面或任何位置（双击即可）
  2. 打开解压后的文件夹 → 找到 构建寻典.command
    右键单击 → 选"打开"（首次必须右键，绕过 Gatekeeper）
    弹出确认对话框时点"打开"。
    之后每次双击都能直接运行。
  3. 终端窗口自动弹出，开始构建。什么都不用操作——等它跑完即可（首次约 2-3 分钟，后续约 30 秒）。

构建完成后，Finder 会自动弹出，已选中产出文件 dist/寻典.app。 脚本会输出类似：

>>> 6/6  完成！

  📦 产出：~/Desktop/寻典 Mac 构建包/dist/寻典.app（约 80 MB）
  📖 配套手册：~/Desktop/寻典 Mac 构建包/dist/寻典使用说明.pdf

下一步：
  1. 把 dist/寻典.app 和 dist/寻典使用说明.pdf 一起压成 zip
  2. 把 zip 发给最终用户
  3. 用户解压后右键 → 打开 寻典.app（首次需绕过 Gatekeeper）

✓ 全部完成

遇到问题怎么办

脚本提示怎么处理
未找到 Python 3 脚本会自动打开 Python 官网下载页。下载 macOS 64-bit universal2 installer（.pkg），双击安装一路下一步。装完再次双击 构建寻典.command。
Python 版本太旧 同上，去 python.org 下新版（推荐 3.12 或 3.13）。
依赖安装失败 检查网络（pip 需要联网）。如果在国内网络受限，可以让脚本走清华镜像（联系开发者获取改后的脚本）。
PyInstaller 打包失败 把整个终端窗口截图发给开发者。最常见原因是依赖装到了不同 Python 解释器——重启终端再来一次往往能解决。
"开发者无法验证"弹窗 这是正常的 Gatekeeper 拦截。右键 构建寻典.command → 打开，弹窗里再点"打开"。仅首次需要。

分发产物

构建完成后，dist/ 目录里有两个东西要发给最终用户：

文件说明
寻典.app主程序，约 80 MB
寻典使用说明.pdf面向最终用户的图文手册

把这两个一起选中，右键 → 压缩 → 得到一个 zip 文件，发给最终用户即可。

⚠ 不要把整个"寻典 Mac 构建包"文件夹发给最终用户
最终用户只需要 寻典.app 和使用说明 PDF。源代码和构建脚本是你（构建者）的工作目录，发给他们没用，还可能造成困扰。

小知识

  • 构建结果跟着 Mac 架构走：Apple Silicon Mac 出的 .app 在 M1+ 上跑得最快；Intel Mac 出的是 x86_64 通用版，能在所有 Mac 上跑（M1+ 上通过 Rosetta，略慢）
  • 第一次构建慢，之后快：脚本会创建 .venv-mac-build/ 虚拟环境，下次运行直接复用
  • 清理重来：删除 .venv-mac-build/ 和 dist/、build/寻典/，再次双击脚本即可全新构建

一、这本说明书是给谁看的

你正在写一篇论文或一本书，里面引用了大量古籍 / 文献中的句子。 按学术规范你需要为每一处引用标注出处——书名、作者、出版社、年份、具体页码。

传统做法是：翻一本厚书，找到那句话所在的页码，在脚注里写一遍 GB/T 7714 格式。 几十处引用就要重复几十遍——耗时、易错、还要核对页码是不是 PDF 文档页码而不是书的内文页码。

寻典帮你自动完成这件事：把你常用的书目（PDF）一次性放进它的"书架"， 之后扫描你的 docx 文档，它会找出每一处带引号的引文， 自动定位到对应的书和页码，按 GB/T 7714—2015 国家标准生成脚注。

📌 阅读这份手册不需要任何代码 / 命令行经验
整个软件是用鼠标点击操作的图形界面。所有提到的"按钮""标签"在 app 里都能看见、能点。

二、解压与第一次启动

1. 解压并放入"应用程序"

  1. 找到开发者发给你的 zip（如 寻典-v1.0-mac.zip），双击解压
  2. 得到 寻典.app（图标是一本书的图案）
  3. 把 寻典.app 直接拖到"应用程序"文件夹（或留在桌面也可以）
💡 macOS 的 .app 是单一文件夹
寻典.app 看起来是一个文件，实际是文件夹（macOS 把它显示成单一图标）。 整体移动、复制、重命名都没问题——不像 Windows 版那样需要旁边一个 _internal 目录陪着。

2. 第一次打开（重要！必须右键打开）

⚠ 直接双击会被 macOS 拦下来
寻典是个未经 Apple 公证的应用，第一次打开时 macOS 的 Gatekeeper 会拦住， 弹出 ""寻典"无法打开，因为无法验证开发者" 这样的提示。

这不是说软件有问题——所有未购买苹果开发者证书（$99/年）的开源 app 都会被这样拦。 下面教你怎么用三秒钟绕过。

正确打开方式（首次）：

  1. 在 Finder 里找到 寻典.app（应用程序文件夹或你放的位置）
  2. 右键单击 寻典.app，从菜单选 "打开" （注意：是右键里的"打开"，不是双击）
  3. 弹出确认对话框："macOS 无法验证开发者……仍要打开吗？"，点 打开
  4. 之后每次双击都能直接打开，不再弹任何提示
💡 macOS 13 / 14 / 15 上略有不同
在比较新的 macOS 上，右键 → 打开后可能要在系统设置里再确认一次：
系统设置 → 隐私与安全性，往下滚找到"已阻止使用 寻典.app 因为来自身份不明的开发者"， 右侧点 "仍要打开"。然后回到 Finder 双击寻典就能用了。

3. 启动后的界面

  1. 启动需要 2~5 秒
  2. 主窗口弹出。第一次打开会自动停在 📚 我的书架 标签页， 显示一张欢迎卡片（因为还没添加任何书）
  3. 顶部从左到右：寻典 logo / 三个标签 / 右上角的设置齿轮 ⚙
  4. 底部是状态栏，长操作时会在这显示进度
💡 添加到 Dock
寻典启动后，图标会出现在 Dock 上。右键 Dock 图标 → 选项 → 在程序坞中保留， 以后就能从 Dock 一键启动，不用每次去应用程序找。

三、整体使用流程速览

第一次完整跑通寻典只需要做这四步：

① 把书加进书架→ ② 等自动解析→ ③ 扫描 docx→ ④ 复制 / 导出脚注

之后日常使用就只是步骤 ③ 和 ④ ——书架是一次配置，长期使用。

三个标签页用来做什么
📚 我的书架 管理你导入的 PDF 书目：添加、分类、补全出版信息、移除等
📄 文档扫描 选一份 docx 文档，自动扫描其中所有「""」引文并定位出处
🔍 单句查询 不扫整篇文档，只查某一句话的出处
⚙ 设置（右上角） 调整匹配相似度、查看数据目录、关于信息等

四、核心概念

概念 含义
书架 你提前导入的 PDF 书籍的集合。寻典查找引文时只在书架里的书查；书架没有的书自然找不到出处。
文件夹 书架内的分类标签——比如"胡适研究""明史史料""期刊论文"。一本书属于一个文件夹（或不分组）。方便日后只在某个子集里查找。
解析 程序把 PDF 每一页的文字提取出来缓存，便于以后秒查。每本书只解析一次，结果永久保存。
引文 你 docx 文档里所有用 引号 "" 包起来的句子（中文弯引号 "" 或英文 "" 都识别）。扫描时把每一处引号内容都拿去查。
脚注 按 GB/T 7714—2015 国家标准生成的引用条目，例如：
胡适. 胡适日记全编·五[M]. 合肥: 安徽教育出版社, 2001: 24.
命中 / 未命中 ✓ 自动命中 在书架里找到完全一致的来源
⚠ 置信度偏低 找到相似但不完全一致的位置（OCR 误差或引用不精准），需人工核对
✗ 未命中 书架里没找到——可能源自其他文献，或这条根本不是真引文（如对话）
查找范围 每次扫描或查询时，可以限定只在某些文件夹 / 某几本书里查，不必每次都扫整个书架。详见 6.2。

五、建立你的书架

5.1 添加 PDF（支持一次多本）

在 📚 我的书架 标签页，右上角可以看到三个按钮：

按钮功能
+ 添加书籍添加新 PDF 到书架（最常用）
+ 新建文件夹建一个空文件夹，之后把书拖进去
☑ 多选进入多选模式，对多本书做批量操作

添加 PDF 的标准流程：

  1. 点 + 添加书籍
  2. 弹出文件选择窗口。按住 Ctrl 键可以选多个 PDF；按住 Shift 键选连续的一段。选完点"打开"
  3. 弹出"放入哪个文件夹"对话框（可选）：
    • 选已有文件夹
    • 选 + 新建文件夹… 现场建一个
    • 不选（保持"未分组"）也可以
  4. 点"继续导入"。程序会逐本快速登记，然后弹出 解析进度模态框
  5. 模态框里每本书一行：左侧文件名、中间进度条、右侧"412/898"页码计数
  6. 所有书解析完后，"取消"按钮自动变成 完成，点击关闭
💡 解析期间能取消
解析进度模态框底部有 取消解析 按钮——点了之后已经在解析的那本完成后停止， 剩余的不再处理。已经解析完的书不丢。后续可以在书架卡片上点 ⚙ 解析 继续。

解析需要多久？

书的厚度大约时间
200 页以下5-15 秒
500 页（如《胡适日记》）30-60 秒
1000 页以上1-3 分钟

解析结果会被缓存。同一本书第二次启动 app 时立即可用，不需要重新解析。

5.2 用文件夹分类管理

书少的时候不分类也行；超过 5 本以上建议按主题分文件夹，扫描时可以只在相关子集里查找，速度更快、噪声更少。

新建文件夹

  1. 点书架右上角 + 新建文件夹
  2. 输入名字（如"胡适研究""明清史料"），确定
  3. 新文件夹会作为一行折叠区出现在书架，刚建时是空的

把书移进文件夹（三种方式）

方式操作适用场景
① 直接拖动 鼠标按住书卡片，拖到目标文件夹的标题区 移一两本，最快
② 点书卡上的 📁 移动 按钮 弹出选择目标文件夹的小框 没法拖（如折叠了）的情况
③ 多选 → 批量移动 开启多选模式，勾选多本，点工具条 📁 移到文件夹 一次移多本到同一个文件夹

重命名 / 删除文件夹

每个文件夹标题右侧有 重命名 和 删除 两个小按钮。

  • 重命名：弹框输入新名字
  • 删除文件夹：里面的书会自动移到"未分组"，书本身不删

折叠 / 展开

点文件夹标题（除去按钮区域）即可折叠或展开该文件夹下的书。书多时折叠不常用的文件夹能让书架清爽。

5.3 多选模式：批量操作

当你想一次对多本书做相同操作时（比如都重新解析一次），用多选模式：

  1. 点书架右上角 ☑ 多选 按钮，进入多选模式
  2. 每本书卡片左侧出现复选框，可点击勾选；点卡片本体也会切换勾选
  3. 顶部出现工具条：
按钮作用
全选勾选所有书
取消选择清空所有勾选
批量解析解析所有"待解析"的勾选书
批量重新解析清缓存重抽（很少用，仅在缓存损坏时）
📁 移到文件夹把勾选的书一起移到某文件夹
批量移除从书架移除（PDF 文件不删）

结束多选：再点一次按钮（这时显示为 ✕ 退出多选）。

5.4 编辑书籍出版信息

新添加的书，作者 / 出版社 / 年份等字段都是占位值（XX 或 XX出版社）。 建议添加后立即补全，否则生成的脚注里会带占位符。 书架卡片会以 出版信息待补 黄色标签提醒你。

  1. 找到要编辑的书卡片
  2. 点卡片右下角 ✏ 编辑 按钮
  3. 填入所有字段，包括"文件夹"
  4. 点"确定"保存

文献类型代码

代码含义
M专著（最常见，默认）
J期刊文章
N报纸文章
D学位论文
R研究报告

5.5 重新解析 / 移除书籍

每张书卡片上有一组小按钮，作用各异：

📁 移动 移到其他文件夹
✏ 编辑 修改出版信息
⚙ 解析 仅未解析的书才有；点击启动解析
🔄 重新解析 仅已解析的书才有；清除缓存重抽。通常不需要用——只在某次缓存损坏或软件升级了抽取逻辑时才有意义
🗑 移除 从书架移除。不会删除你电脑上的 PDF 原文件——只是从书架名单去掉

六、文档扫描

6.1 选择 docx 与扫描过程

  1. 切到 📄 文档扫描 标签页
  2. 查看顶部"📂 查找范围"——默认是 全部书架，如想限定可点 更改（详见 6.2）
  3. 点 📂 选择 docx 文件
  4. 选中你要核对引文的 Word 文档（必须是 .docx，不支持老的 .doc）

扫描过程会经历这些阶段：

  1. 统计引文总数：先扫一遍文档，找出所有用引号 "" 包起来的句子。 底部状态栏显示 找到 32 条引文，准备开始查询…
  2. 加载书架数据 + 预处理书目文本：从缓存读所有相关书的文字，做归一化（简繁、全角、标点等统一）
  3. 逐条查询：每查完一条立即在窗口里显示一张结果卡片。状态栏显示 扫描中 13/32 进度
  4. 完成提示：全部查完弹出汇总对话框：共 N 条 / 命中 X / 偏低 Y / 未找到 Z
💡 不用等扫完才看结果
程序边查边出。第一张卡片可能 1-2 秒就出现了， 你可以一边浏览前面的结果，程序一边继续查后面的。

6.2 限定查找范围

默认会在整个书架里查每一条引文。当书架越来越大时，限定范围有两个好处：

  1. 更快——只搜索相关的几本，速度按比例提升
  2. 更准——避免无关书里恰好同字偶发的误命中

设置范围的步骤

  1. 在 📄 文档扫描 顶部找到"📂 查找范围"卡片，点 更改
  2. 弹出"选择查找范围"对话框，是一棵树形结构：
    • 顶部有 全部书架 总开关
    • 下面是每个文件夹（带勾选框，可整体勾选）
    • 每个文件夹展开后是该文件夹里的书（可单独勾选）
    • 最下方是"未分组"组（把不在任何文件夹的书归到这）
  3. 勾选你想包括的文件夹或单本书
  4. 点"确定"。卡片显示"📁 胡适研究、📁 明清史料 （6 本）"等概要
💡 半选标记
当一个文件夹下只有部分书被勾选时，文件夹复选框会显示"半选"小横线 — 状态。 此时点该复选框会一键全选或全不选其下所有书。

单句查询页签也有同样的查找范围卡片，独立设置（互不干扰）。

6.3 看懂结果卡片

✓ 自动命中　[1] 引文

不便带他去

出处（建议）：胡适. 胡适家书[M]. 合肥: 安徽教育出版社, 2001: 131.

原文上下文：……招待所须自备铺盖，「不便带他去」，遂权衡再三……

📋 复制脚注 📖 在 PDF 中查看

字段 解释
状态徽章左上角的 ✓ / ⚠ / ✗ 标签，一眼看出该条是否找到
引文你 docx 里的原句（去掉了引号）
出处（建议）程序按 GB/T 7714 拼出的脚注。这里的页码是书内页码（书右下角印的那个），不是 PDF 文档页码。

书中片段书里命中位置前后那一段原文，可一眼比对是否就是你要找的

卡片上的两个按钮

📋 复制脚注 把这一条的脚注文本复制到剪贴板，可直接粘到 Word
📖 在 PDF 中查看 用 Edge 浏览器打开该 PDF 并自动跳到对应页，便于二次核实

6.4 多个候选时怎么挑

有时同一句话在几本不同的书里都出现过（比如 "有肺病" 同时出现在胡适日记和家书里）。 寻典会按"语境匹配度"排序，把最可能的那本作为推荐主项；其他列在下方的"其他疑似候选"区块。

每个候选都附带：书 + 页码、相似度分数、书中片段。对照"书中片段"挑最贴近你 docx 上下文的那个， 点该候选的 📖 在 PDF 中查看 进一步核对。

有时程序的"推荐"未必正确，比如多本书里都有同一句但语境分难以拉开差距。 所以候选列表存在的意义就是把决定权交给你——程序只给提示，最终选谁由你判断。

6.5 复制脚注 / 导出核对表

所有引文扫完后，文档扫描页底部出现两个按钮：

📋 复制全部脚注 把所有 "自动命中" 的脚注一次性合并复制到剪贴板，可直接粘进 Word。 （"置信度偏低"和"未找到"的不会自动复制——这些需要你人工核对，强行复制可能出错）
💾 导出核对表 docx 生成完整的 Word 文档，包含每条引文的脚注、上下文、书中片段、所有候选、书目 OCR 质量统计。 中文宋体、英文 Times New Roman，可直接打印或交给同行评审

七、单句快查

有时你只想确认某一句话出自哪里，没必要扫整篇文档。这时用 🔍 单句查询。

  1. 切到 🔍 单句查询 标签页
  2. 顶部"📂 查找范围"和文档扫描的独立——可单独限定
  3. 在"引文"输入框里贴入要查的句子（不要带引号）； 右侧 ✕ 可一键清空
  4. "上下文"可填可不填——填上前后几个字能让结果更准（同一句出现在多本书时帮助挑对的那本）
  5. 点 🔍 查询，或者直接按 Ctrl+Enter
  6. 结果卡片显示在下方，格式与文档扫描完全一致
💡 适合的场景
· 写作中突然想引用一句话，记不清出自哪本
· 同行评审说某条出处可疑，快速复核
· 想看看某句话在书架里出现过几次（多个候选会全部列出）

八、设置面板（齿轮按钮）

点窗口右上角的齿轮按钮 ⚙ 打开设置面板。普通用户保持默认即可；以下情况可以试着调：

8.1 三个匹配参数

参数 默认值 调整方向 & 适用场景
匹配相似度阈值 0.85 调高（如 0.95）：结果更严格，未命中变多但更可信
调低（如 0.70）：结果更宽松，能找回 OCR 模糊的引文，但误判变多
语境分权重 0.10 多本书都命中同一句时，前后文相似度的影响力。一般不用动。
如发现"推荐"经常错（同字不同义的多本书争议时），可调到 0.20-0.30 让语境更主导
每条最多列出候选数 3 每条引文最多展示几条候选（含推荐项）。多了占空间，少了可能漏掉真的来源

三个参数都是 滑块，旁边数字实时变化。改完点 保存。

8.2 数据 / 关于

设置面板下方还有"数据"和"关于"两块：

  • 📂 打开数据目录——直接用 Finder 打开 ~/Library/Application Support/XunDian/， 里面是 books.json / cache / settings.json。 通常不用动这些文件。如果想"重置成全新的寻典"，关掉 app 后删除这整个文件夹即可
  • 恢复默认——把三个参数滑回默认值（保存才生效）
  • "关于"区显示 应用版本 / Python 版本 / 数据目录路径 / 关键依赖状态（opencc 是否可用等）
💡 找不到"资源库"文件夹？
~/Library（资源库）默认在 Finder 里是隐藏的。打开数据目录最方便就是从设置面板点 📂 打开数据目录。
也可以在 Finder 里按 Cmd + Shift + G（前往文件夹），输入路径直达。

九、常见问题

扫描结果"未命中"特别多怎么办

常见原因（按可能性排序）：

  1. 书架里没有相关的书——添加更多 PDF 后再扫
  2. 查找范围太窄——检查"📂 查找范围"是否限定到了不相关的几本书
  3. 引文被你修改过（删了几个字、改了标点）——程序模糊匹配能容忍小幅差异，但改得太多会找不到
  4. 文档里的引号其实不是真引文——比如对话、强调、专有名词。这些"未命中"是正常的
  5. PDF 是图片扫描件，文字层缺失——查看书架上书卡的"低质量"标签

页码标错了

寻典区分"PDF 页码"和"书内页码"——同一页 PDF 文档可能是封面后第 153 页，但书内页码（书右下角印的那个）是 131。 脚注里用的是书内页码，符合学术规范。

如果发现标错（很罕见），多半是因为该书页码识别失败。可以点"在 PDF 中查看"亲自核对一下， 然后在导出的 Word 核对表里手动改正。

添加 PDF 后解析失败 / 卡住

关掉解析进度模态后重启 app，在书架上对那本书点 ⚙ 解析 按钮重试。 反复失败的话，可能是该 PDF 带密码保护或文件损坏——可以用 Adobe Reader 打开看看是否正常。

点"在 PDF 中查看"没跳到指定页

程序优先用 Chrome / Edge / Safari 打开（这些浏览器自带 PDF 查看器，支持锚点跳页）。 如果你电脑上以上三个浏览器都没装（极罕见），会回退到系统默认 PDF 应用， 而 macOS 自带的 Preview（预览）通常不支持自动跳页——只能打开第一页。

解决：装一个 Chrome 或确保 Safari 没被禁用即可。

导出的 Word 字体不一致

寻典生成的核对表中文用宋体、英文/数字用 Times New Roman。如果你打开后看到字体不一致， 可能是 Word 在用其他主题字体覆盖。打开 Word 顶栏"设计"→"字体"，选"Office"主题即可恢复。

书架里删了文件夹，里面的书还在吗

在。删除文件夹只是删了"分类标签"——书会自动移到"未分组"分组里，书本身和元信息都不丢。

能不能改了 books.json 直接生效

理论上可以，但不推荐——格式有 v2 版本要求（有 folders / books 两个字段）。 最稳妥的方式是通过 app 界面操作。如果不小心改坏了，删除 books.json 重启 app 会从零开始（书架变空）。

能在 Windows 上用吗

有 Windows 版（开发者另外提供 寻典-v1.0-windows.zip）。功能完全一样，只是双击运行的是 寻典.exe。

关闭 app 后再次打开会提示什么吗

不会。第一次右键打开后，macOS 已记住你信任这个 app，之后双击直接启动，不会再有任何提示。

能把 .app 拷给同事用吗

可以。把整个 寻典.app 直接拖给对方（zip 一下更稳），对方解压后同样需要右键 → 打开第一次。 书架数据是各人独立的（在各自的 ~/Library/Application Support/XunDian/），互不影响。

Apple Silicon (M1/M2/M3) 还是 Intel Mac

取决于打包人的 Mac 是什么架构：在 Apple Silicon Mac 上打包出的 .app 是 arm64 原生的（在 M1+ 上跑得最快）， 在 Intel Mac 上打包出的是 x86_64（也能在 Apple Silicon 上跑，但通过 Rosetta 略慢）。两种都是 64 位。

支持 doc / pages / 其他格式吗

当前只支持 .docx 输入和 PDF 书库。如有需要可在反馈里提。

十、已知限制与版本说明

v1.0 已知限制

  • 只能匹配 PDF 自带文字层。纯图片扫描的 PDF 找不到（书架里会显示低质量标签提醒你）
  • 不会自动写脚注到原 docx 里。当前生成核对表 + 复制脚注两种方式，研究者需要把脚注粘贴到正文。下一版会做"一键插入脚注到原文档"
  • 引文长度小于 3 字（如 "好" "嗯"）会被自动忽略，避免对话引号误命中
  • 同一句出现多次时，程序按语境分排序选最相关的，但若全部书的语境都很弱，可能选错——人工核对一下"其他疑似候选"
  • 多选模式与拖动互斥：开启多选时不能拖动书卡。退出多选才能拖
  • 暂不支持图片型 PDF 的 OCR。如果某本书是纯图片扫描，需要先用其他工具加上文字层（比如 Adobe Acrobat 的"文字识别"）再添加进书架
